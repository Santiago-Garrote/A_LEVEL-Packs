# A-Level Trainer packs

Study packs for [A-Level Trainer](https://santiago-garrote.github.io/A_LEVEL-Trainer/), served at
https://santiago-garrote.github.io/A_LEVEL-Packs/ (`index.json` + one `.zip` per subject).

The packs are not committed to git: they are the assets of the [`packs` release](../../releases/tag/packs).
The workflow publishes those assets to GitHub Pages. To update, from the A-Level Trainer repo run
`nix run .#publish`, which uploads `data/packs/*` to the release and redeploys.
